{# =========================================================================== Shared UI macros for the whole web app. Added 2026-09-30 with the light-theme redesign. Before this file the same seven visual blocks were hand-copied across 26 templates -- the stat card 20+ times, the table skeleton 5 times, the empty state in 7 mutually incompatible markups, and one business rule (the attendance threshold) copy-pasted at least six times. Everything here takes its colours from a `data-tone` attribute rather than a class name. WHY data-tone AND NOT A CLASS: Tailwind's build scans source text for complete class-name tokens. When a class name is split across a Jinja expression -- a literal prefix, then an opening brace, then a fragment the scanner reads as its own token -- the assembled name never appears in the file, the rule is never emitted, and the element renders unstyled with no error anywhere. An attribute selector makes the class a permanent literal and lets only the free-form attribute value vary, which removes that whole class of silent failure. See input.css for the matching .pill / .dot / .progress-fill / .bar-fill / .alert rules, and tests/test_templates.py::test_no_split_tailwind_class_names for the guard that keeps it that way. =========================================================================== #} {# --------------------------------------------------------------------------- ATTENDANCE THRESHOLDS These are two DIFFERENT rules that look alike, and the distinction is load-bearing: * at_risk_tone() mirrors a real business rule: "below 75% is at risk". That threshold is hardcoded in Python in four places -- blueprints/student.py and api/student.py compute at_risk_count as pct < 75, and blueprints/hod.py counts flagged students the same way in two places. A student at 70% genuinely IS flagged, so red is correct in the student and HOD views. Keep this in step if the Python threshold ever moves -- it is currently duplicated there, not hoisted to a shared constant. * grade_tone() is a three-tier portfolio scale used by the admin reports and the department rollup, where a single number summarises many students and "70% of a cohort" should not read as one student's red flag.
